# Secondhand Supply

Static website for the Secondhand Supply SEO/GEO class project.

## Files

- `index.html` — home page
- `shop.html` — sample shop with filtering and sorting
- `how-it-works.html` — process page
- `about.html` — brand story
- `faq.html` — questions and policy checklist
- `contact.html` — demo contact form
- `styles.css` — responsive visual design
- `script.js` — product data, filters, modal details, forms, and mobile menu
- `sitemap.xml` and `robots.txt` — search-engine files
- `netlify.toml` — Netlify publish configuration

## Before publishing

1. Replace `example.netlify.app` in each HTML file, `robots.txt`, and `sitemap.xml` with the real Netlify URL or custom domain.
2. Replace the six fictional products in `script.js` with real inventory, photos, prices, measurements, and condition details.
3. Replace the placeholder email, social handle, shipping policy, returns policy, and contact workflow.
4. Connect the forms to an approved form service if you need real submissions.
5. Add Google Search Console after the site is live and submit `sitemap.xml`.
